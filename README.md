# Faouzia Player

## 🎶 About
This desktop app is a music player for my favourite artist "Faouzia" in pixel art style, it contains the best songs of her.

## 🛠️ Made with
- HTML
- CSS
- JS
- Electron.js

## 🚀 How to Start
You can get the setup file from the "Releases" section and install the app normally.
